# Searon Maharjan — Portfolio

> Two-tone editorial portfolio for Searon Maharjan, website and app designer and frontend developer based in Kathmandu, Nepal.

## Tech Stack
- Next.js (App Router)
- React 19 & TypeScript
- Tailwind CSS 4
- GSAP & ScrollTrigger
- Lenis Smooth Scroll
- Raw WebGL & Canvas 2D
- Bodoni Moda & Geist Typography

## Repository size
The project recordings are committed in `public/projects/`. Decided 2026-11-24: superseded recordings stay in history, and video stays in git (no LFS). At about 50 MB, stripping the roughly 10.5 MB of old video would rewrite every commit hash and break other clones for little gain. Revisit only if the repository passes about 150 MB.
